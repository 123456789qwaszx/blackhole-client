## 1. 목표 [사용자]

1. 플레이하면 전투 창이 아니라 **업그레이드 화면**이 나온다.
2. 업그레이드 화면에서 **노드를 순차적으로 해금**할 수 있다. 이 브랜치의 기능은 이것뿐이다.
3. 노드 도구에서 고친 모양(노드의 격자 칸, 선)이 **게임 창에서도 그대로** 보인다.
4. 개발용 콘솔에서 Gold를 **100, 1,000, 1만, 100만, 1억, 100억, 1조** 단위로 더하고 뺄 수 있고, **전체 노드 해금**과 **전체 노드 잠금**을 할 수 있다.

## 3. 정리한 것 (NS-001, PLAN 전에 끝냄) [사용자]

지금 상태를 `feature/업그레이드연결`에 남긴 뒤, 이 브랜치에서 노드 트리 화면과 순차 해금에 무관한 것을 지웠다.

| 지운 것 | 남긴 것 |
|---|---|
| Core: Common(전투 난수·공간), Content(판 조립 콘텐츠·로더), Enemies, Session, World, Upgrades | Core: `Nodes`(그래프·구매·로더), `Players/PlayerState`(Gold·산 노드), `Content/ContentDiagnostic` |
| 노드의 업그레이드 칸, `NodePurchase.UpgradesFor`, "전투 중에는 살 수 없다"(`InBattle`) | 노드: ID, 가격, 시작 노드, 격자 칸, 선 |
| Sample(판 설정), 적·풀·단계 에셋 | `Data/NodeCatalog.asset` (사용자가 도구로 고친 배치 그대로) |
| Unity: Battle, Enemies, 전투 화면, 전투·적·조종 콘솔, 노드 목록 콘솔, 적 콘텐츠 에셋 스크립트 | Unity: GameHost(최소), 화면 흐름 틀, 임시 화면 틀, 콘솔 부품, 노드 목록 에셋 |
| 계약: 콘텐츠·판·적·업그레이드, 전투가 필요한 진행 상태 계약 | 계약 13개: 하네스 1, 진행 상태 2, 노드 트리 4, 편집 규칙 6 |
| 노드 도구의 업그레이드 편집·합계 | 노드 도구: 격자 편집, 선, 명령, 검사, 구매 미리보기 |

합칠 때는 `feature/업그레이드연결`이 기준이다. 그 브랜치의 노드 트리는 이 브랜치와 같은 구조에 업그레이드 칸과 전투 규칙이 더 있다.

## 4. 흐름

```text
노드 목록 에셋 (NodeCatalog: NodeTreeData)
   │  NodeTreeLoader
   ├─▶ NodeTree ── Graph: 노드 ID, 시작 노드, 선(목록), 드러남
   │             └ Nodes: ID, 가격
   └─▶ 격자 칸 (X, Y)  ← 표시용. 규칙은 읽지 않는다

진행 상태 (PlayerState: Gold, 산 노드)
   ▲ 구매 NodePurchase.TryPurchase        ▲ 개발용 치트 ProgressCheats
   │                                      │
업그레이드 화면 (UpgradeScreen) ◀── ScreenFlow ──▶ 개발용 콘솔 (UpgradeConsole)
   노드 누름 → 노드 ID                      Gold ±, 전체 해금, 전체 잠금
   ◀ 노드마다 상태(NodePurchase.StateOf), Gold, 산 노드 수
```

- 화면은 규칙을 모른다. 노드마다 칸·가격·상태와 선 목록을 받아 그리고, 눌린 노드 ID를 알린다.
- 화면 흐름(ScreenFlow)이 구매 규칙을 부르고, 진행 상태가 바뀐 프레임에만 화면을 다시 칠한다. 콘솔이 Gold나 산 노드를 바꿔도 같은 길로 반영된다.

## 5. 업그레이드 화면 명세

### 5.1 배치 — 노드 도구와 같은 좌표

- 칸 (X, Y)의 노드는 화면의 트리 공간에서 (X × 칸 크기, Y × 칸 크기)에 놓인다. X는 오른쪽, Y는 위쪽이다. 노드 도구와 같은 방향이다.
- 칸 크기 120, 노드 크기 84 [제안]. 도구(칸 72, 노드 52)와 비율이 같아 모양이 같다.
- 선은 두 노드의 중심을 잇는 곧은 막대다. 선은 노드 아래에 그린다.
- 선은 그래프(`NodeGraph.Links`)에서 읽는다. 저작 데이터의 `Links`를 화면이 직접 해석하지 않는다.

### 5.2 상태와 보이기

| 상태 (`NodeState`) | 보이기 | 색 [제안] | 누르면 |
|---|---|---|---|
| Hidden | 그리지 않는다 [원작] | — | — |
| Revealed (Gold 부족) | 보인다 | 회색 | 아무 일 없음 |
| Purchasable | 보인다 | 노랑 | 산다 |
| Owned | 보인다 | 초록 | 아무 일 없음 |

- 숨은 노드를 그리지 않는 것은 원작을 따랐다(사야 그 너머가 드러난다). 전체 모양은 콘솔의 전체 해금으로 확인한다. 실루엣으로 보여 줄지는 F02에서 다시 정한다.
- 선은 양 끝이 모두 보일 때만 그린다. 양 끝을 모두 산 선은 밝게, 아니면 어둡게 칠한다 [제안].
- 노드 글자: ID와 가격(천 단위 쉼표). 산 노드는 가격 대신 "owned"다. 글자는 TMP 기본 글꼴이라 영문·숫자다(기존 임시 화면과 같다).
- 화면 위쪽: `Gold 1,234,567` · `3 / 8 nodes`.

### 5.3 조작 [제안]

- 노드 클릭: 살 수 있으면 산다(원작처럼 누르면 바로 산다).
- 빈 곳 끌기: 이동. 휠: 커서 위치를 중심으로 확대·축소(0.3 ~ 2.5배).
- 화면이 열릴 때 노드 전체(숨은 노드 포함)의 범위가 보이게 맞춘다. 저작한 모양의 가운데가 화면 가운데다.
- 노드 위에서 끌어도 이동이다. 끌었으면 떼어도 사지 않는다.

## 6. 개발용 콘솔 명세 [사용자]

- 창 하나(오른쪽 아래. 오른쪽 위는 화면의 산 노드 수 글자와 겹친다), ` 키로 숨기고 보인다. 에디터와 개발 빌드에서만 만든다(기존 콘솔과 같다).
- 첫 줄: 현재 Gold.
- Gold 더하기 줄: `+100` `+1K` `+10K` `+1M` `+100M` `+10B` `+1T` (100 · 1,000 · 1만 · 100만 · 1억 · 100억 · 1조).
- Gold 빼기 줄: 같은 7단계의 `-`. **0 밑으로 내려가지 않는다** [제안]. 가진 것보다 많이 빼면 0이 된다.
- 노드 줄: `Unlock all`, `Lock all`.
  - 전체 해금: 모든 노드를 산 것으로 한다. Gold를 쓰지 않는다. 숨은 노드도 포함한다 [제안].
  - 전체 잠금: 산 노드를 모두 지운다. Gold는 돌려주지 않는다 [제안].

## 7. 코드 구조

| 곳 | 파일 | 책임 |
|---|---|---|
| Core | `NodeGraph.Links` | 선 목록(한 선에 한 번). 로더가 만든다 |
| Core | `Players/ProgressCheats` (새) | 개발용 치트: Gold 빼기(0에서 멈춤), 전체 해금, 전체 잠금. 구매 규칙을 거치지 않는다는 것이 이름에 드러난다 |
| Core | `PlayerState` | 치트가 부르는 내부 입구: Gold 빼기, 노드 소유, 소유 비우기 |
| Unity | `Screens/UpgradeScreen` (새) | 화면(UIRoot). Gold·진행 글자, 트리 보기. 노드 클릭을 노드 ID로 알린다 |
| Unity | `Screens/NodeTreeView` (새) | 트리 보기: 노드·선 만들기, 상태 칠하기, 확대·이동, 전체 맞추기. 규칙을 모른다 |
| Unity | `Screens/PlaceholderScreens` | 업그레이드 화면의 임시 틀(배경, 위쪽 글자, 트리 영역) |
| Unity | `Flow/ScreenFlow.Upgrade` (새) | 업그레이드 화면 ↔ 노드 트리·진행 상태. 구매를 부르고, 바뀐 프레임에만 다시 칠한다 |
| Unity | `Console/UpgradeConsole` (새) | 개발용 콘솔 |
| Unity | `GameHost` | 노드 트리·진행 상태·UI·화면 흐름·콘솔 조립. 시작 화면 = 업그레이드 화면 |

- 화면은 UIPresentationFlow의 `UIRoot<Refs>`를 따른다. 자식 이름(Refs)만 맞추면 나중에 사용자가 만든 프리팹으로 바꿔 끼울 수 있다(기존 전투 화면과 같은 약속).
- 트리 보기는 uGUI다(Image·Button·TMP). 선은 회전한 얇은 Image다. 외부 패키지를 더하지 않는다.

## 8. 계약

새로 보장하는 동작만 더한다.

- `Node.GraphListsEachLinkOnce`: 양쪽에 적은 선도 선 목록에 한 번만 나온다.
- `Progress.CheatsBypassPurchaseButGoldStaysNonNegative`: Gold 빼기는 0에서 멈춘다. 전체 해금은 Gold를 쓰지 않고 숨은 노드까지 산 것으로 한다. 전체 잠금 뒤에는 구매 규칙이 처음부터 다시 적용된다.

화면·콘솔은 Unity 쪽이라 계약 대신 플레이로 확인한다(9절).

## 9. 확인 방법

1. CoreSmoke 계약 통과, Unity 밖 컴파일(Core·Unity·Authoring·Editor), Unity 에디터 로그의 빌드 성공.
2. 플레이 (사용자):
   - 업그레이드 화면이 뜨고, 시작 노드만 보인다.
   - 콘솔 `+100` → 시작 노드가 노랑 → 누르면 초록, Gold가 가격만큼 준다, 이어진 노드와 선이 나타난다.
   - `Unlock all` → 모든 노드와 선이 보이고, 노드 도구의 모양과 같다.
   - `Lock all` → 시작 노드만 남는다.
   - `-1T` → Gold가 0이 된다(음수가 되지 않는다).
   - 휠과 끌기로 확대·이동된다. 노드 위에서 끌어도 사지 않는다.
