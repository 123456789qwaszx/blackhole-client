# 레퍼런스 분석 — A Game About Feeding A Black Hole

조사일: 2026-09-24 · 대상: Aarimous & Thornity 개발, 2025-12-15 출시(Steam app 3694480, itch.io 데모)

## 1. 이 문서의 범위

우리 게임이 레퍼런스로 삼는 게임의 구조를 정리한다. 공개 자료와 사용자 플레이 관찰을 바탕으로 한다. [GAME_RULES](GAME_RULES.md)의 미정 항목을 정할 때 근거로 쓴다.

- 이 문서는 레퍼런스의 사실과 관찰이다. 우리 게임의 규칙이 아니다. 우리 규칙은 GAME_RULES가 정한다.
- 레퍼런스의 내부 구현을 확인한 것이 아니다. 수치는 대부분 공개되지 않았다.

## 2. 한 판(세션)

- 한 판은 제한 시간이 있는 짧은 세션이다. 시간이 끝나면 업그레이드 화면으로 간다. [공식]
- 초반 세션은 10~20초 정도로 짧다. [플레이어]
- 필드의 물체는 유한하다.
  - 화면의 물체를 전부 부수면 세션을 일찍 끝내는 버튼이 나온다. [공식]
  - 메인 모드에서도 초반 업그레이드만으로 전부 부수는 업적이 있다. [공식]
- 물체를 다 부쉈는데 블랙홀이 자라지 않았으면, 남은 시간을 그냥 기다려야 한다(The Line 모드 불만). [플레이어]
- 일정 시간마다 물체가 새로 나온다는 근거는 찾지 못했다.
- 돈은 판마다 번다. 돈 업적이 "한 세션에서 $10 ~ $1T"다. [공략]

## 3. 블랙홀 성장

- 블랙홀은 Level을 가진다. Level마다 채워야 하는 물질량이 점점 늘어나고, 화면에 진행 막대가 있다. [공식, 플레이어]
  - 로그라이크 모드 기록 "12.56"은 Level 12를 넘기고 Level 13의 약 절반까지 채웠다는 뜻이다. [공식]
- **블랙홀이 자라면 소행성이 추가되고 시간이 늘어난다.** [사용자] 플레이어 보고도 "시간은 블랙홀이 자랄 때만 늘었다"로 같다. [플레이어]
- **성장으로 추가되는 소행성의 양은 업그레이드 노드로 늘릴 수 있다.** 이 노드는 트리의 극초반에 있다. [사용자]
- 성장하면 블랙홀이 커진다. 커지는 것은 화면뿐이고 맵이 넓어지지 않는다는 리뷰 비판이 있다. [공식, 플레이어]
- 성장 업적은 모두 "한 세션 안에서"가 조건이다. [공략]
  - 이름 붙은 Milestone이 Level 10, 20, 30, 35, 40, 41, 42 부근에 있다.
  - 최대 크기에 도달하면 메인 모드를 클리어한다.
- 한 플레이어가 "한 판에 Level 6까지 키웠는데 다음 판은 1이었다"고 적었다. [플레이어] 그래서 Level은 판마다 1부터 다시 시작하는 것으로 보인다. [추정]
- Milestone 보상은 존재한다(보상은 올림만 한다는 패치 노트). 내용은 확인하지 못했다. [공식]
- 물질은 부서진 조각이 블랙홀로 빨려 들어갈 때 들어온다. 조각이 주위를 돌기만 해서 성장이 멈추는 버그 제보가 여러 건 있다. [플레이어]
- 성장했다는 화면 피드백이 약해서 알아채기 어렵다는 의견이 있다. [플레이어]

## 4. 물체(우리의 적)와 공급

**종류** [공식, 플레이어]

| 물체 | 특징 |
|---|---|
| 소행성 | 여러 등급·크기. 가장 기본 |
| 행성 | 단단하다. 처음 만나면 진행이 잠시 느려진다 |
| 달 | 행성 주위에 붙어 다닌다. 행성과 함께 부수면 버프 |
| 별 | 레이저 별, 초신성 |
| 혜성 | 한꺼번에 쏟아지는 이벤트. 커서가 치명타를 내게 하는 버프 |
| 별똥별 | 치명타 버프 |

**특수 물체** [공식, 플레이어]

| 물체 | 효과 |
|---|---|
| 전기 소행성 | 부서지면 주변에 연쇄 번개 |
| 방사능 소행성 | 부서진 뒤 피해를 주는 구름을 남긴다 |
| 황금 소행성 | 돈 배율. 치명타가 나면 큰돈 |

**공급**
- 시작 배치 수는 업그레이드로 늘어난다. "50개 이상으로 시작" 업적이 있고, 물체 수·밀도·크기 업그레이드가 있다. [공략, 플레이어]
- 블랙홀이 자라면 소행성이 추가된다. 추가량은 업그레이드로 늘어난다. [사용자]
- 물체를 부술 때 새로 나올 확률이 있다(예: 행성이 부서지면 새 행성이 나올 확률 업그레이드). [공식]
- 혜성은 한꺼번에 쏟아진다. [플레이어]
- 새 물체 종류(행성, 달, 별, 특수 소행성)는 업그레이드로 해금한다. [공식, 공략]

**파괴와 흡수**
- 물체는 피해를 받을수록 작은 조각으로 쪼개진다. 조각은 블랙홀 주위를 돌다가 빨려 들어간다. [공식, 플레이어]
- 물체는 블랙홀 주위를 돈다. [플레이어]

## 5. 공격(Breaker)

- 커서의 원이 주기적으로 자동 피해를 준다. 클릭하는 방식이 아니다. [플레이어]
- 업그레이드: Damage, Radius, Speed(Rate), 치명타. [공략]
- 피해의 대부분이 커서에서 나온다는 리뷰가 있다. [플레이어]

## 6. 특수 효과 규칙 [공식: 개발자 답변]

- 효과는 물체가 부서질 때 발동한다.
- 효과는 트리 업그레이드로 강화한다. 전기의 경우 연쇄 수, 갈라질 확률, 기본 피해를 올린다.
- 높은 등급 물체일수록 효과 피해가 커지는 숨은 배율이 있다.
- 특수 효과는 다른 특수 물체의 효과를 발동하지 않는다.
  - 이유 1: 재등장 확률 때문에 연쇄가 무한히 이어지고 렉이 생겼다.
  - 이유 2: 플레이어가 특수 물체를 직접 부수는 편이 더 재미있다고 판단했다.

## 7. 업그레이드 트리

- 세션 사이에 유지되는 영구 트리다. 메인 모드는 200개 이상의 노드를 가진다. [공식]
- 모드마다 자기 트리가 있다. [공식, 공략]
- 돈으로 사며, 비용이 점점 오른다. [플레이어]
- 개발자가 훨씬 많은 노드를 담을 수 있게 트리 로딩을 바꿨다. [공식] 트리를 데이터로 정의하는 것으로 보인다. [추정]
- 사는 순서가 거의 정해져 있어 선택의 폭이 좁다는 비판이 있다. [플레이어]
- 메인 모드 트리는 거의 직선이다. 판이 끝날 때마다 살 수 있는 노드가 1~2개만 보이고, 새 기능이 몇 판마다 열린다. 개발자는 편안한 흐름을 위한 의도라고 답했다. [공식, 플레이어]
- 다른 모드는 격자형 트리다. 숫자 강화 노드 여러 개가 구매 선택을 두고 경쟁한다. [공식, 플레이어]
- 트리는 구역과 막 단위로 나뉜다. 출시 직후 노출된 개발용 패널에 "다음 구역 풀기", "다음 막 풀기" 버튼이 있었다. [공식]
- 노드는 위치, 비용, 수치 보정(mod)을 가진다. 패치 노트에 노드 위치 이동, 비용 변경, 노드 추가·삭제, mod 값 조정이 함께 나온다. [공식]
- 프레스티지나 판 밖의 메타 진행은 없다. 모드를 한 번 끝내면 그 모드는 끝이다. [플레이어]
- 트리 모양 [사용자 스크린샷]
  - 가운데 육각형 시작 노드에서 선이 뻗고, 노드 묶음(3×3 격자, 십자 모양)이 선으로 이어진다.
  - 묶음은 색(초록, 파랑, 보라, 빨강)으로 구분된다. 구역으로 보인다. [추정]
  - 회색 자물쇠 노드 묶음이 있다. 아직 잠긴 구역으로 보인다. [추정]
  - 같은 아이콘이 한 묶음에 여러 개 있다. 한 노드를 여러 번 사기보다 단계마다 별도 노드를 사는 구조로 보인다. [추정]
  - 산 노드와 연결된 노드가 다음 구매 후보가 되는 것으로 보인다. [추정]
- 화면 흐름 [공식, 플레이어]
  - 시간이 끝나거나 Esc의 "세션 끝내기"를 누르면 업그레이드 화면으로 간다. 거기서 다음 세션을 시작하며, 구매는 유지된다.
  - "New Game"은 저장을 덮어쓰기 전에 확인을 받는다. 진행 전체를 초기화한다.
- 알려진 노드 종류:
  - Breaker의 Damage, Radius, Speed, 치명타
  - 세션 시간
  - 부술 때 시간 추가(효과가 미미하다는 제보) [플레이어]
  - 시작 물체 수, 밀도, 크기
  - 성장 시 추가되는 소행성 수 [사용자]
  - 돈 배율
  - 특수 물체의 해금·등장 확률·효과 강화
  - 새 물체 종류 해금

## 9. 우리 GAME_RULES와 비교

| 주제 | 레퍼런스 | GAME_RULES | 비고 |
|---|---|---|---|
| 적 공급 | 유한한 시작 배치 + 성장 시 추가 + 파괴 시 재등장 확률. 주기 생성 근거 없음 | 시작 배치 + 성장 구간 공급을 우선 검토. 주기 생성은 확정 아님(9절) | 방향이 같다 |
| 성장 효과 | 성장할 때마다 소행성 추가 + 시간 증가 | 일반 레벨업과 특정 구간을 구분한다(9절) | 레퍼런스는 매 성장에 효과가 있다. Milestone Level의 추가 효과는 미확인 |
| 추가량 강화 | 성장 시 추가되는 소행성 수를 초반 노드로 늘린다 | 적 물량 증가 → 적 공급 구성(8절) | 같은 연결. 공급량이 구매 보정을 받는 값이어야 한다 |
| EXP가 들어오는 시점 | 조각이 빨려 들어갈 때 | 사망 확정 때. 흡수는 연출(4·10절) | 우리 규칙이 일부러 다르다 |
| Level 유지 | 판마다 1부터로 보임 | 다음 전투의 유지 범위는 미정(4절) | M6 결정의 근거 후보 |
| HQ 크기 | 화면만 커진다 | 시각 크기와 생성 공간을 구분(12절) | 시각 크기만 바꾸는 쪽이 레퍼런스와 같다 |
| 특수 효과 연쇄 | 효과가 다른 특수 효과를 발동하지 않음 | 대기열로 연쇄 처리, 연쇄 범위는 미정(11절) | M7의 참고 |
| 업그레이드 | 영구 트리, 비용 증가, 모드별 트리, 노드가 많다. 노드 = 위치·비용·mod. 구역 잠금이 있다 | Gold로 노드 구매, 선행 노드와 가격(8절). HQ 레벨에 의한 직접 해금은 아직 도입하지 않음 | M6의 참고. 노드 저작과 트리 배치는 별도 툴의 일 |

## 10. 아직 모르는 것

- 성장 1회에 늘어나는 시간과 추가되는 소행성의 기본 양
- Level별 필요 물질량 곡선과 시작 물체 수
- Milestone 보상의 내용
- GAME_RULES 9절에 관찰로 적은 "주변 천체를 전부 끌어당기는 효과"가 나오는 Level과, 그것이 처치인지 연출인지
- 성장이 업그레이드 해금이나 새 물체 종류의 등장과 연결되는지
- 트리 구역의 잠금이 풀리는 조건
- 원과 물체가 겹치기만 해도 맞는지(피격 판정)
