# M5 — HQ 성장과 진행 구간·적 공급

상태: 계획 · 선행: M4 · 기획 또는 임시 샘플 확인 후 착수

## 목표

HQ EXP → Level과 구간 도달 → 시간 연장/적 공급의 경계를 최소 예제로 확인한다. 레퍼런스 내부 규칙을 복제했다고 주장하지 않는다.

## 착수 전에 정할 것

- EXP 임계값, 일반 레벨업과 특별 구간의 관계.
- 시작 배치와 구간별 추가 수량/종류, 시간 연장량.
- 같은 단계의 처치·구간 도달·시간 종료 우선순위.
- 추가 적이 해당 단계에 즉시 맞는지 다음 단계부터 맞는지.
- HQ 시각 크기만 바꿀지, 생성 최소 거리도 바꿀지. 미정이면 공간 공식은 넣지 않는다.

## 범위

1. HQ 성장 상태와 공유 성장 정의 분리. 샘플 임계값 사용.
2. 구간 효과는 진행 처리에 둔다. HQ가 직접 적을 생성하거나 타이머를 변경하지 않는다.
3. 공급 구성 결정과 실제 생성 분리. 확인된 샘플에서 초기 배치와 구간 추가를 사용하고 종전 자동 주기 생성은 제거한다.
4. 세션별 가변 시간 예산을 두고 공유 TimeLimitDefinition을 수정하지 않는다.
5. 샘플 성장 표시. 전체 적 흡수/전멸은 규칙이 미정이므로 구현하지 않는다.
6. Content/검증/Sample과 출현·시간·스킬 계약을 함께 갱신한다.

## 완료 기준

- 초기 배치는 1회. 도달한 구간의 공급/시간 효과도 1회.
- EXP가 여러 임계값을 넘는 경우 각 해당 구간을 중복/누락 없이 처리.
- 긴 프레임과 짧은 프레임에서 같은 구간 진행 결과. 임계값 전/동일/후 확인.
- 시간 연장 후에도 종료/진행 제한이 같은 시간 원본 사용.
- 같은 콘텐츠로 만든 두 세션의 시간·HQ·공급 상태는 독립.
- 첫 틱 0초는 유지하되 초기 적이 생긴 새 조건에 맞는 실제 피해 검증.
- 사용자 확인: 성장 표시, 공급, 시간 연장, 종료.

## 비범위와 결과

구매·영구 저장·HQ 전투 능력·전체 전멸·실제 게임의 밸런스 복제 제외. 결과: 미구현.
