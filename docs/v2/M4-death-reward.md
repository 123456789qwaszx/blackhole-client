# M4 — Death → Reward와 흡수 연출

상태: 계획 · 선행: M3, 결정 D4

## 목표

Enemy의 HP가 0 이하가 되는 순간 Death가 확정되고, 그 순간 Gold와 EXP가 수령 Player에게 한 번 지급된다. 게임 규칙상 Enemy는 그때 끝난다. 블랙홀로 빨려드는 것은 화면이 그 뒤에 보여 주는 연출이다.

## 검증할 경계

- **B6 Death → Reward**
  - HP <= 0 → Death 확정 → 보상 계산·지급이 한 흐름에서 일어난다.
  - 같은 Enemy의 Death와 보상은 한 번뿐이다. 같은 틱에 여러 피해가 겹쳐도 마찬가지다.
  - 보상은 전역이 아니라 **수령 Player**의 PlayerState로 간다. 수령자를 정하는 자리가 하나 있다.
- **B1 Player 단위**: Gold와 EXP가 Player마다 구별되어 쌓인다.
- **B7 Presentation 분리**
  - 게임 규칙상 Enemy는 Death 확정 때 끝난다(더 이상 피해·행동·선택 대상이 아니다).
  - 화면은 Death를 알고, 사망 위치에서 HQ로 빨려드는 연출을 재생한 뒤 View를 지운다.
  - 연출이 느려지거나 생략돼도 보상은 바뀌지 않는다. View 제거 시점은 Death 시점과 다르다.

## 범위

- Enemy 생명주기: Alive → Dead. Death 확정은 Enemy(상태의 주인)가 판정한다.
- 보상: Enemy 종류의 보상 Gold/EXP(M2에서 정의만 해 둔 값)를 수령 Player의 PlayerState에 더한다.
- 수령자 결정: [임시] Death를 일으킨 피해의 출처 Player.
- 게임 규칙상 제거: Death 확정 이후 Enemy 목록에서 빠진다(또는 Dead로 남되 모든 시스템이 무시한다. 어느 쪽인지는 이 마일스톤에서 정한다).
- 화면이 Death를 아는 방법(아래 질문).
- 흡수 연출: 사망 위치 → HQ, 일정 시간, 끝나면 View 제거. 연출 값은 표현 정의에만 둔다.
- HUD: Player의 Gold/EXP 표시.

## 비범위

- Level 계산(D4), 레벨업 결과.
- Gold 사용처(강화, 상점).
- 종류별 사망 효과(폭발, 분열 등).
- HQ 성장(D1).

## [임시] 값

- 보상 수령자 = Death를 일으킨 피해의 출처 Player.
- Enemy 종류별 보상 Gold/EXP.
- 흡수 연출의 길이와 경로(Presentation 전용).

## 이 마일스톤에서 정할 질문

- **화면은 Death를 어떻게 아는가?** 게임 규칙상 Enemy가 목록에서 빠지면 화면은 "사라졌다"만 알고, 사망인지 다른 이유인지와 사망 위치를 모른다. 후보는 다음과 같다.
  - (a) 판이 "이번 단계의 사망 기록"(Enemy, 위치, 수령자)을 남기고, 화면이 매 프레임 읽는다. v1의 "화면은 읽기만" 방식을 유지한다.
  - (b) 사망 이벤트를 발행하고 화면이 구독한다. 구독 연결·해제 수명을 따로 검증해야 한다.
  - 권장은 (a)다. 결정 후 결과 절에 이유를 남긴다.
- **Dead Enemy를 목록에서 바로 빼는가, 남겨 두는가?** 빼면 "모든 시스템이 Dead를 무시한다"는 규칙이 필요 없고, 남기면 화면이 위치를 계속 읽을 수 있다. (a)를 택하면 빼는 쪽이 단순하다.

## 작업 순서

1. Enemy Death 전이와 판정.
2. 수령자 결정 자리와 보상 지급(PlayerState에 Gold/EXP).
3. 게임 규칙상 제거.
4. 화면이 Death를 아는 방법 결정과 구현.
5. 흡수 연출과 View 제거.
6. HUD의 Gold/EXP.
7. 계약 테스트(Death, 보상 1회, 수령자, 제거, 연출 독립성).

## 완료 기준

- **자동 계약**
  - HP가 0 이하가 되는 단계에서 Death가 확정되고, 같은 단계에 보상이 수령 Player에게 지급된다.
  - 같은 틱에 여러 피해가 겹쳐도 Death와 보상은 한 번이다.
  - Dead Enemy는 더 이상 피해·선택·행동의 대상이 아니다.
  - 보상은 수령 Player의 PlayerState에만 쌓인다(테스트에서 Player 2명을 만들어 확인한다. 게임 콘텐츠는 1명).
  - 화면 쪽 처리 없이도(연출 없음) 보상 결과가 같다.
- **플레이 확인**: Enemy가 죽으면 즉시 Gold/EXP가 오르고, Enemy는 사망 위치에서 HQ로 빨려 들어간 뒤 사라진다. 연출 중인 Enemy는 다시 맞지 않는다.

## 재점검 항목

- 보상이 연출의 끝(View 제거)에 묶이지 않았는가?
- "Player가 하나"라는 가정 없이 수령자가 정해지는가?
- 흡수 관련 값(속도, 경로)이 게임 규칙 쪽에 새지 않았는가?
- Level·Gold 사용처를 몰래 정하지 않았는가?
