# M4 — Death, Player Gold / HQ EXP, 흡수 연출

상태: 계획 갱신 · 선행: M3 · 아직 미구현  
기준: [GAME_RULES](../GAME_RULES.md), [PLAN](PLAN.md). 종전 Player EXP 지급 계획을 대체한다.

## 목표와 범위

- HP <= 0에서 적이 사망을 한 번 확정하고 즉시 후속 피해·선택·이동 대상에서 제외된다.
- Gold는 현재 단일 PlayerState, 성장 EXP는 HQ에 반영한다.
- Enemy 정의/검증에 보상 Gold와 HQ EXP를 추가한다. M2에는 보상 필드가 없다.
- 보상은 같은 사망 처리 흐름에서 1회 반영하며 View 제거를 기다리지 않는다.
- 목록 제거는 순회 안전한 지점에서 수행하되 Dead 적을 그 사이 다시 처리하지 않는다.
- DeathRecord를 읽어 흡수 연출을 한다. 프레임 사이에 생성됐다 사라져 View가 없던 적도 기록으로 표현 가능해야 한다.
- HUD에서 Player Gold와 HQ EXP를 구분한다.
- 현재 타이머 생성은 M5 전 과도기 상태로 유지한다.

## 구현 시 경계

피해 수용 → 즉시 Death 전이/후속 대상 제외 → 보상·사망 기록 1회 → 안전한 목록 제거.
모든 Skill이 끝날 때까지 Death 자체를 미루지 않는다. 선택 목록에 이미 담긴 적도 적용 시 생존을 다시 확인한다.
M7의 연쇄 효과가 같은 사망 경로를 쓸 수 있게 하되, 아직 범용 효과 엔진은 만들지 않는다.

DeathRecord는 Advance 한 번의 모든 하위 단계를 누적하는 방식으로 계획한다. 다음 Advance에서 교체하되, 일시정지·종료 중 같은 기록을 다시 읽어 연출을 중복 생성하지 않도록 배치 식별/소비 계약을 구현 전에 명시한다. 새 전투에서는 소비 상태와 View를 함께 초기화한다.

실제 1인 보상 구성은 실행 전 검증한다. 다인 보상 정책은 만들지 않고, 기존 두 Player 소유권 테스트는 보상 없는 단위 조립이나 테스트 대역으로 유지한다. 피해 출처를 Gold 수령자로 쓰지 않는다.

## 비범위

HQ 레벨 곡선·구간 효과(M5), 구매(M6), 사망 효과(M7), Player Level, 다인 보상 정책.

## 샘플과 완료 기준

- 샘플: 적별 Gold/HQ EXP, Presentation 전용 흡수 시간·경로.
- 여러 Skill/틱이 겹쳐도 사망·Gold·HQ EXP·사망 기록은 적마다 1회.
- 죽은 적은 이후 이동·선택·피해를 받지 않음.
- 긴 Advance에서 모든 사망 기록 유지. 반복 Synchronize에 중복 연출 없음.
- 연출을 끄거나 지연해도 Gold/HQ EXP 동일.
- 종료/공간 정리는 처치 보상을 발생시키지 않음.
- 사용자 플레이: 즉시 Gold/HQ EXP 증가, 후속 흡수, 재시작 시 옛 기록/연출 없음.

## 결과

미구현. 자동 검증 및 사용자 플레이 확인 후 작성한다.
