# M7 — 적의 사망 효과와 연쇄

상태: 계획 · 선행: M6 · 첫 효과 선택 후 착수

## 목표

적 사망 특성 하나를 연결해 플레이어 Passive Skill·적 특성·Presentation의 책임을 구분한다.

## 범위

- 적 종류 정의에서 사망 효과 지정. 첫 효과는 폭발/전기/레이저 중 하나만 선택한다.
- 적은 Death 전이, 전투 처리는 대상/피해, 보상 처리는 Gold/HQ EXP, 화면은 연출 담당.
- M4 사망 경로를 재사용한다. 연쇄 사망은 큐로 처리하고 적끼리 재귀 호출하지 않는다.
- 같은 적의 보상·효과는 한 번. Dead는 후속 선택/피해에서 제외한다.
- 연쇄 피해의 출처 표기와 구간 전환/시간 종료의 처리 순서를 구현 전에 정한다. 출처를 보상 수령 정책으로 바꾸지 않는다.
- 성장 구간의 전체 정리와 일반 사망 효과를 혼동하지 않는다.

## 완료 기준

- A 사망 효과가 B를 죽일 때 각 적의 보상·효과 1회.
- 이미 죽은 적 재선택 및 중복 큐 처리 방지.
- 유한한 적 집합의 연쇄가 종료되고 재귀 호출로 쌓이지 않음.
- 화면이 없어도 피해·Gold·HQ EXP 동일.
- 구간 변경/종료와 겹치는 사례의 결과가 정한 순서와 일치.
- 긴 프레임 중 연쇄 사망 기록이 화면에서 유실되지 않음.

## 비범위와 결과

부활·무한 생성·분열·범용 효과 그래프·모든 특수 효과 제외. 결과: 미구현.
